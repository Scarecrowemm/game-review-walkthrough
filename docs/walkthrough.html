Layer B · 卡关点

机制拆解、思路、容错窗口与失败信号1 条

钟楼钟摆总是被撞下去

第 3 章 · 沉没钟楼

失败信号反复在钟摆的第三摆被撞落，多数玩家会误判为跳跃距离不足，实际是被前一摆的余波推到判定区

在考什么这一关考的不是跳跃精度，是「起跳时机必须绑定钟声」而不是绑定视觉位置。钟摆在画面上有视觉滞后，用眼睛跟会晚约半拍

思路闭眼跟声——把注意力从钟摆本体移到音效上，钟声响起即为起跳信号，不要等看到钟摆到位

  1. 站在平台最内侧，等第一摆过去后再上钩索，避免开局就被余波推走
  2. 听到钟声立刻起跳，不用确认钟摆位置
  3. 落点选在平台靠外三分之二处，给下一摆留出后撤空间

容错窗口钟声到起跳的容错窗口约 0.5 秒；平台外侧有约 0.3 秒的后撤冗余，但窗口在第三摆会缩短

常见错误

  • 用视觉跟钟摆 → 稳定晚半拍，在第三摆被撞
  • 贪输出在平台上多打一下 → 后撤空间不足，被余波推落
  • 失败 5 次后改用听声法，连续 3 次通过
  • 素材平台外侧三分之二处即为安全落点区域 · captures/ch3_bell.png

阶段血量区间招式循环出招读法安全输出窗口低容错点
1 100%-65% 横扫 → 横扫 → 突进，三步固定循环，无随机分支 横扫前右肩会先下沉约 0.3 秒；突进前有半秒停顿且脚下扬灰 两次横扫之间有 2 秒安全窗口，可打满一套轻击；突进撞墙后有 3 秒硬直 突进若未撞墙则直接衔接横扫，此时没有输出窗口，后撤即可
